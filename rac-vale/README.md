# Auditoria de RAC – endereço antigo

O aplicativo mudou para um repositório próprio:

- Código: https://github.com/nelsivansouza40-web/RAC-CAMPO
- Endereço: https://nelsivansouza40-web.github.io/RAC-CAMPO/

Esta pasta mantém apenas o aviso de mudança (`index.html`) e um service
worker que remove a versão antiga guardada nos aparelhos (`sw.js`).
O motivo da mudança: o Inspeções SSMA, instalado, abrange todas as
subpastas de `/projetos-claude/` e abria o RAC dentro da própria janela.
